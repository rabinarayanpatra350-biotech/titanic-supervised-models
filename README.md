# Titanic Dataset — Supervised Machine Learning Models (Regression + Classification)

**Week 2 Task: Supervised Machine Learning Models** (Internship project by Rabi Narayan Patra)

Building on the [Week 1 preprocessing pipeline](https://github.com/rabinarayanpatra350-biotech/titanic-data-preprocessing), this project trains, evaluates, and **compares seven supervised learning models** with scikit-learn:

| Model | Task | Best result (held-out test set) |
|-------|------|----------------------------------|
| Logistic Regression | Classification (Survived) | **84.9% accuracy, 0.797 F1, 0.876 ROC-AUC** |
| Decision Tree | Classification (Survived) | 83.2% accuracy, 0.773 F1 |
| Random Forest | Classification (Survived) | 79.9% accuracy, 0.823 ROC-AUC |
| K-Nearest Neighbors | Classification (Survived) | 77.1% accuracy |
| Linear Regression | Regression (Fare) | **£10.88 MAE, R² 0.58** |
| Random Forest | Regression (Fare) | £11.77 MAE, R² 0.47 |
| K-Nearest Neighbors | Regression (Fare) | £14.16 MAE, R² 0.26 |

**Key findings:**
- The simple linear models beat the ensembles on this small tabular dataset
- The Random Forest classifier overfits: 98.5% train accuracy vs 79.9% test
- Log-transforming the skewed fare target halved regression error
- Survival is driven by fare, age, title, and sex (feature importances below)

## Evaluation protocol

- 80/20 train/test split (712 train / 179 test), stratified for classification
- 5-fold stratified cross-validation on the training set
- Classification metrics: accuracy, precision, recall, F1, ROC-AUC
- Regression metrics: MAE, RMSE, R² (in pounds; models train on log-fare)
- KNN uses a StandardScaler pipeline; trees and linear models use raw features

## How to run

```bash
pip install -r requirements.txt
python train_models.py
```

Place `titanic.csv` in the same folder as the script (download it from
[Release v1.0](https://github.com/rabinarayanpatra350-biotech/titanic-supervised-models/releases/tag/v1.0)
or from the Week 1 repository). The script writes:

- `classification_results.csv` — metric table for the four classifiers
- `regression_results.csv` — metric table for the three regressors
- `figures/` — the five PNG charts shown above
